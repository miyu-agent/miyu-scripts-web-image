# 网络搜图

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `web_image`，可以上网搜索图片，按要求的张数存进用户的图片目录，并且把前面最多 4 张直接给 AI 看。如果要给人看，AI 会再用 `show` 打开对应的文件。

## 参数

工具的参数如下：

| 参数 | 说明 |
|---|---|
| `query` | 必须填写。要搜索的内容。 |
| `count` | 保存的张数，范围是 1–20，默认是 4。 |
| `safe_search` | 是否过滤成人内容，默认开启。关闭时，中文查询会额外搜索百度和 360（这两家没有安全搜索）。 |

## 行为

这一节说明工具搜索、保存和展示图片的方式：

- 来源：工具同时搜索 DuckDuckGo 和必应，按标题和查询词的吻合程度、分辨率排序，去掉重复的结果（同一张原图、同一个文件）之后再下载；如果原图下载不下来，就改用缩略图。
- 图片存到图片目录（`MIYU_PICTURES_DIR`）下的 `网络搜图/<查询词>-<时间>/01.jpg`……，按排名编号，不会自动清理。群聊、陌生人私聊这类会话没有图片目录，此时图片存到脚本缓存目录（`MIYU_CACHE_DIR`）下的 `images/`，只保留最近 10 次搜索。工具不会往工作区里写任何东西。
- 给 AI 看的图片遵循 Miyu 的规格：格式是 PNG、JPEG、GIF 或 WebP，大小不超过 5 MiB，每条边不超过 8000 像素，最多 4 张；不符合规格的图片只保存，不附给 AI。
- 工具只连接公网地址，每一次跳转都会检查，并且实际连接的就是检查过的那个地址。代理使用的假 IP 段（198.18.0.0/15）会放行，因为走代理时目标地址由代理解析。
- 如果某个来源拒绝访问（403、验证码），工具会让它冷却 10 分钟；如果超时或断线，冷却 2 分钟。冷却记录存在脚本缓存目录里。

`Clicall: no`：由于 AI 在命令里用 `miyu call` 调用这个工具时拿不到图片，所以只允许直接调用。软件包的清单里写了 `needs = ["images"]`，因此在显示不了图片的会话（语音）里，整个软件包不会启用。

这个工具只使用 Python 标准库。
