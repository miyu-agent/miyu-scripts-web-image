# 网络搜图

Miyu 的脚本包，带一件工具 `web_image`：上网搜图，照要的张数存进用户的图片目录，前至多 4 张直接给 AI 看。要给人看，AI 再用 `show` 打开对应的文件。

## 参数

| 参数 | 说明 |
|---|---|
| `query` | 必填，搜什么 |
| `count` | 存几张，1–20，默认 4 |
| `safe_search` | 过滤成人内容，默认开；关掉时中文查询会多搜百度、360（这两家没有安全搜索） |

## 行为

- 来源：DuckDuckGo、必应同时搜，按标题和查询词的吻合度、分辨率排序，去重（同一原图、同一文件）后下载；原图下不下来的退到缩略图。
- 存到图片目录（MIYU_PICTURES_DIR）下的 `网络搜图/<查询词>-<时间>/01.jpg`……，按排名编号，不自动清。群聊、陌生人私聊这类会话没有图片目录，退回脚本缓存目录（MIYU_SCRIPT_CACHE_DIR）下的 `images/`，只留最近 10 次搜索。不往工作区写东西。
- 给 AI 看的图照 Miyu 的规格：PNG、JPEG、GIF、WebP，不超过 5 MiB、每边不超过 8000 像素，至多 4 张；不合的只存不附。
- 只连公网地址，每一次跳转都查；代理的假 IP 段（198.18.0.0/15）放行。
- 哪个来源被拦（403、验证码）就冷却 10 分钟，超时、断线冷却 2 分钟，记在脚本缓存目录里。

`Clicall: no`：AI 在命令里用 `miyu call` 调它拿不到图，所以只许直接调。清单写了 `needs = ["images"]`，显示不了图片的会话（语音）里整包不开。

只用 Python 标准库。
