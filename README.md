# Web image search

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `web_image`, which searches the web for images, saves as many as you ask for into the user's Pictures folder, and shows up to the first 4 directly to the AI. If a person needs to see them, the AI then opens the matching files with `show`.

## Parameters

The tool takes these parameters:

| Parameter | Description |
|---|---|
| `query` | Required. What to search for. |
| `count` | The number of images to save, from 1 to 20. The default is 4. |
| `safe_search` | Whether to filter adult content. It is on by default. When it is off, Chinese queries also search Baidu and 360 Search (neither of which has a safe search). |

## Behavior

This section explains how the tool searches for, saves and shows images:

- Sources: the tool searches DuckDuckGo and Bing at the same time, ranks the results by how well the title matches the query and by resolution, removes duplicates (the same original image or the same file) and then downloads them; if an original image cannot be downloaded, it uses the thumbnail instead.
- Images are saved under `网络搜图/<query>-<time>/01.jpg` … in the Pictures folder (`MIYU_PICTURES_DIR`), numbered by rank, and are never cleaned up automatically. Sessions such as group chats and private chats with strangers have no Pictures folder; in that case the images go to `images/` in the script cache folder (`MIYU_CACHE_DIR`), which keeps only the 10 most recent searches. The tool never writes anything into the workspace.
- Images shown to the AI follow Miyu's limits: PNG, JPEG, GIF or WebP, no larger than 5 MiB, no more than 8000 pixels on each side, and at most 4 of them; images that do not fit are only saved, not attached.
- The tool connects only to public addresses, checks every redirect, and connects to exactly the address it checked. The fake IP range used by proxies (198.18.0.0/15) is allowed, because when you use a proxy the proxy resolves the target.
- If a source blocks the tool (403 or a captcha), the tool rests that source for 10 minutes; after a timeout or a dropped connection, it rests the source for 2 minutes. These cooldowns are recorded in the script cache folder.

`Clicall: no`: because the AI gets no images when it calls this tool through `miyu call` in a command, only direct calls are allowed. The package manifest declares `needs = ["images"]`, so in sessions that cannot display images (voice), the whole package is turned off.

The tool uses only the Python standard library.
